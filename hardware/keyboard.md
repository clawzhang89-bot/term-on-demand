## 方案 B：TourBox Elite（一体触摸+按键）

唯一量产的"按键+触控"一体设备。但它是为设计师/剪辑师设计的，需要确认按键位置是否能适应终端操作。

## 方案 C：Beam Pro 触屏 + 迷你 Macropad

```
Beam Pro 本身就是触摸板（6.5寸）+ 浏览器 + 终端 + 语音输入
迷你蓝牙 Macropad（6键）处理 Ctrl/C/V/Tab/Esc 等精确操作
```
