# AI Prompt 示例

## 场景：让 AI 写一个可视化页面

```markdown
我在云端 Ubuntu 上，Nginx root 在 /var/www/html/。
写一个 bash 脚本，功能如下：

1. 采集当前系统信息（CPU负载、内存使用、磁盘空间、网络流量）
2. 生成一个 HTML 文件到 /var/www/html/sysinfo.html
3. HTML 页面使用 Chart.js CDN，展示：
   - CPU 使用趋势（最近 1 分钟采样）
   - 内存使用饼图
   - 磁盘空间条形图
4. 页面样式干净、暗色主题、适合 AR 眼镜阅读
5. 不要常驻进程，每次运行生成一次
```

## 场景：日志分析页面

```markdown
写一个 shell 脚本，接受一个日志文件路径作为参数。

1. 分析日志文件的行数、关键错误关键词频率
2. 生成一个 HTML 页面到标准输出（或指定路径）
3. 包含：
   - 日志摘要统计信息
   - 按时间分段的错误分布（如果日志有时间戳）
   - 关键词搜索框（浏览器端 JavaScript 实现过滤）
4. 页面自包含，不需要后端服务
5. 暗色主题，大字体，适合远距离阅读
```

## 场景：当前目录浏览器

```markdown
写一个 bash 脚本，接受一个目录路径作为参数。

1. 递归扫描该目录，生成文件树
2. 输出一个 HTML 页面到标准输出
3. 包含：
   - 可折叠/展开的文件树（JavaScript）
   - 文件大小、修改时间、文件类型
   - 代码文件语法高亮预览（点击时加载）
4. 纯静态 HTML，使用 highlight.js CDN 做代码高亮
5. 大字号，暗色主题
```

## 场景：通用表格渲染器

```markdown
写一个 bash 脚本，从标准输入读取 CSV/TSV 数据，
生成一个完整的 HTML 表格页面。

功能：
1. 自动检测分隔符（逗号或制表符）
2. 首行作为表头
3. 支持排序（点击表头）
4. 支持搜索过滤
5. 暗色主题，大字体
6. 输出到文件或标准输出
```

## 给 AI agent 的预制 Skill 定义（用于 OpenClaw / Claude Code）

```markdown
## 技能：sysinfo-html
生成系统状态仪表盘 HTML 页面

用法：用户说"看看服务器状态"
行为：采集 CPU/内存/磁盘/网络 → 生成 HTML → 放在 Nginx 目录 → 通知用户 URL

## 技能：dir-html
生成目录浏览器 HTML 页面

用法：用户说"看看 /var/log 里面有什么"
行为：扫描目录 → 生成可折叠文件树 HTML → 放在 Nginx 目录
```
