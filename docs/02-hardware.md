# 硬件选型分析

## 核心结论

| 角色 | 选型 | 价格 | 理由 |
|------|------|------|------|
| 眼镜 | **XREAL One Pro** | ¥4299 | 全彩显示，57° FOV，文字清晰，适合看终端 |
| 计算终端 | **Beam Pro** | ¥1299-2999 | 独立安卓设备，跑 SSH + 浏览器，不依赖手机 |
| 云端 | 已有的 Ubuntu + Nginx | 已有 | 不变 |

## XREAL vs Rokid

| 对比项 | XREAL One Pro | Rokid Max 2 | Rokid Glasses |
|--------|---------------|-------------|---------------|
| 显示类型 | 全彩 micro-OLED | 全彩 micro-OLED | **单色绿字 micro-LED** |
| FOV | **57°** | 50° | 极窄（字幕级） |
| 亮度 | 500 nits | 600 nits | 1500 nits |
| 重量 | 80g | 75g | 49g |
| 是否能看终端 | ✅ 完全可行 | ✅ 完全可行 | ❌ **单色低分，不行** |
| 二次开发/SDK | ✅ 完整 NRSDK 3.0 | ❌ 无 | ❌ 无 |
| 价格 | ¥4299 | ¥2499 | ¥2499 |

### Rokid Glasses 排除原因

Rokid Glasses 是轻薄款（49g），但它的屏幕是**单色（绿色）micro-LED**，分辨率极低，只能显示几行提示文字/翻译字幕/时间日期。**无法显示一个完整的终端或浏览器**。它适合的是 AI 通知推送场景，不是看代码。

### XREAL One Pro 胜出原因

1. 全彩 1080p 显示，文字边缘清晰
2. 57° FOV，视野够大
3. 自研 X1 芯片，**原生 3DoF 屏幕悬停**（画面固定在空间中，转头不走）
4. 完善的开发者 SDK（Unity、Android NDK）
5. 可选 XREAL Eye 模块扩展 6DoF 和第一人称录像

### 可选：XREAL One（非 Pro）

- FOV 50°，稍小但够用
- ¥2999，性价比更高
- 核心 X1 芯片一样，3DoF 一样

## 关于 Beam Pro 的必要性

Beam Pro 不是必须的。替代方案：

| 方案 | 优点 | 缺点 |
|------|------|------|
| **Beam Pro** | 双 USB-C（边用边充）、空间多窗口、NebulaOS 优化 | ¥1299-2999 额外开销 |
| **三星手机 + DeX** | 已有设备，零成本 | 单口 USB-C，不能边充边用眼镜 |
| **支持 DP 输出的安卓手机** | 已有设备，零成本 | 普通投屏模式，无空间悬停 |

对于"看终端"这个场景，普通 DP 投屏就够用了。Beam Pro 是锦上添花。

## 关于 XREAL Eye（6DoF 模块）

- 价格：¥399
- 重量：1.35g
- 功能：提供 6DoF 空间定位 + 1200 万像素第一人称录像
- 必要性评估：**对于终端场景低**

3DoF（X1 芯片内置）已经能把屏幕固定在空间中。6DoF 额外允许你"走近/绕到屏幕背面看"，但终端屏幕是平的，走进去不会多出信息。

**建议：先买核心设备，到手体验 3DoF 够用就不买 Eye。**
